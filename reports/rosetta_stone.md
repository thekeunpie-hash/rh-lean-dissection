### 2. Replacement Mechanism in the Actual Lean Code
The engine that high-multiplicity auxiliary polynomials over finite fields (Stepanov) and $O(2,n)$ automorphic determinants (multiplicity 2) were meant to provide—**"overwhelming the main term via high vanishing order/divisibility to force upper bounds on prime sums"**—is completely replaced in the actual codebase by the following 3-layer architecture:

2. **Arakelov/Bost Ensemble Slope Inequality Instead of Determinant Multiplicity** `[Verified]`:

## ② Weighted von Mangoldt Sum $\sum_{n \le X} \Lambda(n)(X/n - 1)_+ - X\log X + (1+\gamma)X$

- **Final Verdict**: **`[Same Concept, Renamed]`**

### 1. 1-to-1 Comparison with the Actual Kernel-Active Lean Definitions `[Verified]`
The first-order Riesz/Cesàro weighted von Mangoldt sum presented in the announcement is defined **literally identically—down to signs, constants, and the Euler–Mascheroni constant $\gamma$**—in [StatementOC.lean:11-13](../lean/src/Formalism/StatementOC.lean#L11-L13) (`Formalism.Sz`, `Formalism.Gz`) and for general Dirichlet characters in [Analytic.lean:14-24](../lean/src/Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/Analytic.lean#L14-L24) (`Formalism.HC.An.G`, `Formalism.HC.An.gChi`):

```lean
-- Formalism/StatementOC.lean:11-13 (in_cone=true)

-- Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/Analytic.lean:14-24 (in_cone=true)
def G (y : ℝ) : ℝ :=
  (∑ n ∈ Finset.Icc 1 ⌊y⌋₊, abelian₂ n * max (y / n - 1) 0) -
    y * (Real.log y - 1 - Real.eulerMascheroniConstant)
def gChi {N : ℕ} [NeZero N] (χ : DirichletCharacter ℂ N) (y : ℝ) : ℂ :=
  if χ = 1 then ((G y : ℝ) : ℂ) else sumLamChi χ y + (y : ℂ) * logDerivativeAtOne χ
```
